03 / 03 — Skill

Figma 고도화 스킬

Figma 시안(PC/TB/MB)을 반응형 페이지로 만드는 파이프라인. 커맨드 2줄이면 JSON 추출, 섹션 분할, AI 전달까지 끝납니다.

01

배경 및 문제

Figma REST API로 추출한 JSON을 그대로 AI에 전달하면 중간 요소가 빠지는 일이 반복됐습니다.

문제원인
컨텍스트 초과 뷰포트 하나에 600KB+ → AI 컨텍스트 한도 초과. 필요한 섹션 외 정보가 대부분을 차지
Loose 요소 누락 텍스트·벡터 노드 중 일부가 섹션 FRAME 밖에 위치. 섹션만 읽으면 자동 누락
이미지 유실 parseFills()가 IMAGE 타입을 빈 배열로 반환 → 섹션 JSON에서 이미지 정보 소실
섹션 순서 미전달 파일을 하나씩 참조하고 순서를 별도로 설명해야 했음
해결 전략 — 섹션별 분할 + Loose 요소 자동 귀속 + 이미지 자동 다운로드 + 인덱스 파일로 순서 전달.
02

전체 파이프라인

1
figma_extract.py — raw JSON + 이미지 추출
PC/TB/MB 프레임 URL과 이미지 모음 프레임 URL을 넘기면 raw.json과 images/*.png를 뽑아냅니다.
2
parse_figma.mjs — 섹션 분할 + 인덱스 생성
섹션별 .json / .spec.txt 파일과 {시안}_index.md(섹션 순서 포함)를 만듭니다.
3
Claude에 인덱스 파일만 전달
@pc_index.md 하나로 섹션 순서, 파일 경로, 크기를 한꺼번에 넘깁니다.
{시안}_raw.json Figma 원본 JSON — 폰트/그라디언트/이미지 fill 확인 시 사용
images/*.png 이미지 에셋 자동 다운로드
{시안}_{섹션}.spec.txt 사람·AI가 읽기 좋은 텍스트 형식 — 컴포넌트 구현 시 1차 사용
{시안}_{섹션}.json 완전한 섹션 트리 — 정확한 수치 확인 시 사용
{시안}_index.md 섹션 순서 인덱스 — Claude에 이것 하나만 @참조
03

환경 설정 (최초 1회)

figma.com → Settings → Security → Personal access tokens에서 뽑습니다.

~/.zshrc
export FIGMA_TOKEN="figd_xxxxxxxxxxxxxxxxxxxx" ❯ source ~/.zshrc
사내 네트워크에서 SSL 인증서 검증이 실패할 수 있습니다. 스킬 내부에서 우회하므로 따로 설정 안 해도 됩니다.
04

커맨드 레퍼런스

Step 1 — raw JSON + 이미지 추출
python3 skill/scripts/figma_extract.py \ --url "PC 프레임 URL" \ --url "TB 프레임 URL" \ --url "MB 프레임 URL" \ --image-node "이미지 모음 프레임 URL" \ --types raw,images \ --output ./figma
Step 2 — 섹션 분할 + 인덱스 생성
node parse_figma.mjs --dir ./figma --out ./figma/parsed

parse_figma.mjs 추가 옵션:

옵션설명
--prefix desktop_1920특정 뷰포트만 처리
--section Sec_00_Hero특정 섹션만 처리
--section-prefix Sec섹션 이름 prefix 필터
05

파서가 하는 일

섹션 분할 — 루트 너비의 30% 이상인 FRAME을 섹션으로 잡아 파일로 따로 저장합니다.

Loose 요소 귀속 — 섹션 FRAME 밖에 떠 있는 TEXT, VECTOR, RECTANGLE, GROUP 노드를 y좌표 기준으로 가장 가까운 섹션에 붙입니다. 붙은 요소는 loose_overlays 키로 분리 저장됩니다.

spec.txt 출력 예시:

pc_Sec_00_Hero.spec.txt
[FRAME] Sec_00_Hero 1920x890 @(0,90) fill: #b8c6dc [FRAME] Container 660x381 @(630,230) layout: VERTICAL gap=80 [TEXT] Main_heading 622x148 @(649,284) text: "RTX 4090 서버 / 월 30% 할인된 가격으로" fill: #000000 [FRAME] btn_CTA 383x64 @(768,554) fill: gradient_linear [#0037cc to rgba(5,86,203,0.80)] borderRadius: 40px
06

Claude 프롬프트 가이드

전체 섹션 반응형 구현
PC: @figma/parsed/pc_index.md TB: @figma/parsed/tb_index.md MB: @figma/parsed/mb_index.md 세 시안을 반응형으로 구현해줘. 브레이크포인트: 768px(TB), 1280px(PC) 이미지: figma/images/ 폴더 참고
특정 섹션만 구현
@figma/parsed/pc_Sec_00_Hero.json @figma/parsed/pc_Sec_00_Hero.spec.txt 위 섹션만 Vue 컴포넌트로 구현해줘.
텍스트 누락 검수
@figma/parsed/pc_index.md 의 모든 섹션 JSON text 필드와 @pages/event/xxx/index.vue 의 텍스트를 비교해서 누락된 텍스트 리포트만 해줘. 수정은 하지 마.
공통 구현 규칙 (매번 포함 권장)
- px 수치 그대로 사용 (rem 변환 금지) - 기준 너비: PC 1920px / TB 768px / MB 390px - 한국어 텍스트 word-break: keep-all - 이미지는 figma/images/ 폴더 참고
07

이미지 연결 방법

figma/image-mapping.json의 manual_mapping 섹션을 채웁니다. 최초 1회 작성 후 재사용합니다.

figma/image-mapping.json
"manual_mapping": { "intro": "mainbanner.png", "img": "img01.png", "contact-us": "contact-usbg-1.png" }
이미지 자동 매핑이 안 되는 이유는 디자인 레이어명 ≠ 에셋 파일명 때문입니다. 디자이너와 레이어 명명 규칙을 맞추면 이 단계를 건너뜁니다.
08

디자이너 가이드 — 자동화 컨벤션

파이프라인이 제대로 돌려면 아래 규칙을 지켜주세요.

섹션은 FRAME으로 묶기

타입섹션 인식
FRAME인식됨 ✓
GROUP인식 안 됨 ✗
INSTANCE인식 안 됨 ✗

FRAME 이름 규칙 — Sec_{순서}_{섹션명}

예시: Sec_01_Hero / Sec_02_Benefits / Sec_03_Footer
순서 번호는 두 자리(01, 02, ...)로 맞춰야 출력 순서가 보장됩니다.
Sec_ prefix 없는 FRAME(예: gnb, bg)은 섹션으로 안 봅니다.

반응형 프레임 이름 규칙

기기프레임 이름기준 너비
모바일MB360px
태블릿TB768px
PCPC1920px

작업 완료 체크리스트

핸드오프 전 확인
[ ] 모든 섹션이 FRAME 타입인가? [ ] FRAME 이름이 Sec_숫자_이름 형식인가? [ ] 텍스트·이미지 등 요소가 모두 섹션 FRAME 안에 있는가? [ ] 최상위에 loose 요소가 남아 있지 않은가? [ ] MB / TB / PC 프레임이 각각 분리되어 있는가?
09

개선 이력

두 차례 개선을 거쳐 지금 파이프라인이 됐습니다.

항목이전이후
이미지 다운로드 Figma UI에서 수동 내보내기 --image-node 옵션으로 자동 다운로드
IMAGE fill 처리 parseFills()에서 미처리 → 유실 type: image, imageSlot 형태로 보존
섹션 순서 전달 파일 하나씩 참조, 순서 별도 설명 {시안}_index.md 하나로 전달
추출 커맨드 여러 단계 수동 2줄 커맨드로 표준화
이미지 연결 완전 수동 image-mapping.json에 1회 작성 후 재사용
아직 못 고친 것 — 이미지 slotId 자동 매핑 안 됨 (레이어명 규칙 합의 필요), F-top(네비게이션) 섹션 미배치 (--section-prefix로 수동 지정), styledTextSegments 안 됨 (REST API 한계, Plugin API 전용).
