03 / 03 — Skill

Figma 고도화 스킬

Figma 시안(PC/TB/MB)을 AI 구현용 데이터로 정리하는 파이프라인. 두 단계 명령으로 JSON·이미지 추출과 섹션별 정리를 완료합니다. 정리된 파일을 AI 코딩 도구에 전달해 구현을 요청하세요.

01

한 줄로 설치하기

프로젝트 폴더에서 사용하는 도구에 맞는 명령어 하나만 실행하세요. 추가 선택 없이 현재 프로젝트에 스킬을 설치합니다.

macOS / Linux의 Bash 환경에서 사용할 수 있습니다. curl, tar, Python 3, Node.js가 필요하며, 빠진 도구가 있으면 설치 스크립트가 안내 후 종료합니다.
Claude Code · 프로젝트 설치
curl -fsSL https://figma-advanced.vercel.app/install-skill.sh | bash -s -- --target claude --scope local
Codex · 프로젝트 설치
curl -fsSL https://figma-advanced.vercel.app/install-skill.sh | bash -s -- --target agents --scope local

Claude Code는 .claude/skills/gabia-figma-extract/, Codex는 .agents/skills/gabia-figma-extract/에 설치합니다. 모든 프로젝트에서 사용하려면 명령어 끝의 local을 global로 바꾸세요. 다시 설치하면 기존 스킬을 백업한 뒤 교체합니다.

위 명령은 웹에서 받은 설치 스크립트를 바로 실행합니다. 먼저 내용을 확인하려면 설치 스크립트 보기를 이용하세요.

LLM에게 설치 맡기기

터미널 명령 대신 아래 내용을 Claude Code나 Codex에 붙여 넣어도 됩니다. 프로젝트 파일과 터미널에 접근할 수 있는 환경에서 사용하세요.

에이전트에 붙여 넣을 설치 요청문
현재 프로젝트에 gabia-figma-extract 스킬을 설치해줘.

설치 스크립트: https://figma-advanced.vercel.app/install-skill.sh
스킬 문서: https://figma-advanced.vercel.app/skills/gabia-figma-extract/SKILL.md

1. 설치 스크립트를 다운로드해 내용을 확인해줘.
2. curl, tar, Python 3, Node.js 설치 여부를 확인해줘. 빠진 도구는 설치 방법을 안내해줘.
3. 현재 프로젝트 루트에서 실행해줘.
   Claude Code: bash install-skill.sh --target claude --scope local
   Codex: bash install-skill.sh --target agents --scope local
   임시 폴더에 다운로드했다면 스크립트 절대 경로로 실행하고 작업 디렉토리는 프로젝트 루트로 유지해줘.
   다른 에이전트라면 지원되는 스킬 경로를 확인하고 진행해줘.
4. 설치 위치의 SKILL.md, scripts/figma_extract.py, scripts/parse_figma.mjs가 존재하는지 확인해줘.
5. FIGMA_TOKEN은 설정 여부만 확인하고 값을 출력하거나 채팅으로 요청하지 마.
   미설정이면 로컬 환경변수 설정 방법을 안내해줘.
6. 에이전트 재시작과 스킬 호출 방법을 알려줘.

토큰을 저장소에 기록하지 말고, HTTPS 인증서 검증을 유지해줘.

설치 후 시작하기

1
Figma 토큰 설정
Figma 계정 설정에서 Personal access token을 발급하고 file_content:read 권한을 부여하세요. 아래 명령의 예시 값을 실제 토큰으로 바꾸어 로컬 터미널에서 실행합니다. 토큰을 채팅이나 저장소에 올리지 마세요.
현재 터미널에 설정 · Bash / zsh
export FIGMA_TOKEN="발급받은_Figma_토큰"

이 설정은 현재 터미널에만 적용됩니다. 이 터미널에서 에이전트를 실행하세요. 계속 유지하려면 사용하는 셸의 설정 파일에 환경변수를 등록한 뒤 새 터미널을 여세요.

2
에이전트 재시작
설치된 스킬을 인식하도록 Claude Code 또는 Codex를 다시 시작하세요.
3
스킬 호출
아래 호출문을 에이전트에 입력하세요. 출력 폴더명과 PC / TB / MB 시안 URL을 입력하면 추출과 파싱을 진행합니다. 이미지 모음 프레임 URL은 선택 사항입니다.
Claude Code에서 입력
/gabia-figma-extract
Codex에서 입력
$gabia-figma-extract
사내 인증서가 필요하면 관리자가 제공한 CA 파일을 SSL_CERT_FILE 환경변수로 지정하세요. HTTPS 인증서 검증은 유지합니다.

02

배경 및 문제

Figma REST API로 추출한 JSON을 그대로 AI에 전달하면 중간 요소가 빠지는 일이 반복됐습니다.

문제원인
컨텍스트 초과 큰 JSON은 컨텍스트를 많이 차지합니다. 모델과 전달 방식에 따라 처리 한도에 도달하거나 필요한 요소를 놓칠 수 있습니다.
Loose 요소 누락 텍스트·벡터 노드 중 일부가 섹션 FRAME 밖에 위치. 섹션만 읽으면 자동 누락
이미지 유실 parseFills()가 IMAGE 타입을 빈 배열로 반환 → 섹션 JSON에서 이미지 정보 소실
섹션 순서 미전달 파일을 하나씩 참조하고 순서를 별도로 설명해야 했음
해결 전략 — 섹션별 분할 + Loose 요소 자동 귀속 + 이미지 자동 다운로드 + 인덱스 파일로 순서 전달.
03

전체 파이프라인

1
figma_extract.py — raw JSON + 이미지 추출
PC/TB/MB 프레임 URL과 이미지 모음 프레임 URL을 넘기면 raw.json과 images/*.png를 뽑아냅니다.
2
parse_figma.mjs — 섹션 분할 + 인덱스 생성
섹션별 .json / .spec.txt 파일과 {시안}_index.md(섹션 순서 포함)를 만듭니다.
3
AI 코딩 도구에 인덱스 파일 참조
인덱스로 섹션 순서와 파일 경로를 안내하고, 각 섹션 파일을 읽어 구현하도록 요청합니다.
{시안}_raw.json 추출·가공된 상세 JSON — 폰트/그라디언트/이미지 fill 확인 시 사용
images/*.png 이미지 에셋 자동 다운로드
{시안}_{섹션}.spec.txt 사람·AI가 읽기 좋은 텍스트 형식 — 컴포넌트 구현 시 1차 사용
{시안}_{섹션}.json 파서가 보존한 섹션 트리 — 수치 확인 시 사용
{시안}_index.md 섹션 순서 인덱스 — 각 섹션 파일을 찾아 읽는 출발점
04

직접 실행하기 · 고급 사용법

아래 명령은 설치된 스킬 폴더의 scripts 경로를 SCRIPTS_DIR 환경변수로 지정한 뒤 실행합니다. 예: export SCRIPTS_DIR="$HOME/.agents/skills/gabia-figma-extract/scripts". Claude Code 전역 설치는 .claude/skills, 프로젝트 설치는 해당 프로젝트 아래의 설치 경로로 바꾸세요.
Step 1 — raw JSON + 이미지 추출
python3 "$SCRIPTS_DIR/figma_extract.py" \ --url "PC 프레임 URL" \ --url "TB 프레임 URL" \ --url "MB 프레임 URL" \ --image-node "이미지 모음 프레임 URL" \ --types raw,images \ --output ./figma
Step 2 — 섹션 분할 + 인덱스 생성
node "$SCRIPTS_DIR/parse_figma.mjs" --dir ./figma --out ./figma/parsed

parse_figma.mjs 추가 옵션:

옵션설명
--prefix desktop_1920특정 뷰포트만 처리
--section Sec_00_Hero특정 섹션만 처리
--section-prefix Sec섹션 이름 prefix 필터
05

파서가 하는 일

섹션 분할 — 루트의 직계 자식 중 너비가 루트 너비의 30% 이상인 FRAME을 섹션으로 잡아 파일로 따로 저장합니다.

Loose 요소 귀속 — 섹션 FRAME 밖에 떠 있는 TEXT, VECTOR, RECTANGLE, GROUP 노드를 요소의 세로 중심점이 포함되는 섹션에 붙입니다. 어느 섹션 범위에도 포함되지 않으면 미배치 요소로 남습니다. 붙은 요소는 loose_overlays 키로 분리 저장됩니다.

spec.txt 출력 예시:

pc_Sec_00_Hero.spec.txt
[FRAME] Sec_00_Hero 1920x890 @(0,90) fill: #b8c6dc [FRAME] Container 660x381 @(630,230) layout: VERTICAL gap=80 [TEXT] Main_heading 622x148 @(649,284) text: "RTX 4090 서버 / 월 30% 할인된 가격으로" fill: #000000 [FRAME] btn_CTA 383x64 @(768,554) fill: gradient_linear [#0037cc to rgba(5,86,203,0.80)] borderRadius: 40px
06

Claude 프롬프트 가이드

아래 pc / tb / mb 파일명은 예시입니다. 실제 접두사는 Figma 프레임 이름에서 생성되므로 figma/parsed/ 안의 파일명을 확인해 바꾸세요. 인덱스는 파일 경로와 순서를 안내하며, AI가 각 섹션 파일을 직접 읽을 수 있는 작업 환경이 필요합니다. 기준 너비와 브레이크포인트도 실제 시안에 맞게 조정하세요.
전체 섹션 반응형 구현
PC: @figma/parsed/pc_index.md TB: @figma/parsed/tb_index.md MB: @figma/parsed/mb_index.md 세 시안을 반응형으로 구현해줘. 브레이크포인트: 768px(TB), 1280px(PC) 이미지: figma/images/ 폴더 참고
특정 섹션만 구현
@figma/parsed/pc_Sec_00_Hero.json @figma/parsed/pc_Sec_00_Hero.spec.txt 위 섹션만 Vue 컴포넌트로 구현해줘.
텍스트 누락 검수
@figma/parsed/pc_index.md 의 모든 섹션 JSON text 필드와 @pages/event/xxx/index.vue 의 텍스트를 비교해서 누락된 텍스트 리포트만 해줘. 수정은 하지 마.
프로젝트별 구현 규칙 예시
- 시안의 px 수치를 기준으로 구현하되, 프로젝트의 단위 규칙을 따르기 - 시안 사이 너비에서는 컨테이너·그리드·이미지가 유동적으로 조절되도록 구현 - 기준 너비: PC 1920px / TB 768px / MB 390px - 한국어 텍스트 word-break: keep-all - 이미지는 figma/images/ 폴더 참고
07

이미지 연결 방법

추출기는 이미지 fill의 imageRef를 기준으로 에셋을 다운로드하고, 연결 가능한 이미지에는 imageSlot.actualPath를 기록합니다. 이미지 모음 프레임을 지정하면 해당 프레임의 자식 노드도 내보내고 slotId를 기준으로 경로 연결을 시도합니다.

레이어명과 에셋명이 다르거나 동일한 이름이 중복되면 연결 결과를 확인하세요. 연결되지 않은 이미지는 섹션 JSON과 figma/images/를 대조해 구현 시 경로를 지정합니다. 현재 추출·파싱 스크립트는 별도의 image-mapping.json을 읽지 않습니다.
08

개선 이력

두 차례 개선을 거쳐 지금 파이프라인이 됐습니다.

항목이전이후
이미지 다운로드 Figma UI에서 수동 내보내기 --image-node 옵션으로 자동 다운로드
IMAGE fill 처리 parseFills()에서 미처리 → 유실 type: image, imageSlot 형태로 보존
섹션 순서 전달 파일 하나씩 참조, 순서 별도 설명 {시안}_index.md 하나로 전달
추출 커맨드 여러 단계 수동 추출·파싱 두 단계 명령으로 표준화
이미지 연결 완전 수동 추출 시 actualPath 연결, 연결되지 않은 에셋은 수동 확인
아직 못 고친 것 — 이미지 경로 자동 연결 결과 검수 필요 (이름 불일치·중복 등), F-top(네비게이션) 섹션 미배치 (--section-prefix로 수동 지정), 텍스트 구간별 혼합 서식 복원 미지원 (현재 파서의 제한). REST API의 characterStyleOverrides와 styleOverrideTable을 활용하는 추가 처리가 필요합니다.
