Figma MCP

Figma 공식 MCP 서버를 Claude Code에 등록하면 디자인 파일을 바로 읽고 컴포넌트 구조를 코드로 넘길 수 있습니다.

01

Figma MCP란?

MCP(Model Context Protocol)는 AI가 외부 도구에 직접 붙는 개방형 프로토콜입니다. Figma MCP 서버를 등록하면 Claude Code가 get_design_context, get_screenshot 등으로 Figma 파일을 실시간으로 읽습니다.

언제 MCP를 쓰나 — 디자인 시안 전체 구조 탐색, 컴포넌트 라이브러리 확인에 좋습니다. 픽셀 단위 정확도가 필요하면 JSON 추출도 함께 쓰세요.
02

주요 기능

  • get_design_context 노드의 레이아웃, 컴포넌트 구조, 스타일을 JSON으로 뽑아줍니다.
  • get_screenshot 특정 프레임의 스크린샷을 캡처해 눈으로 확인할 때 씀.
  • get_libraries 팀 공유 컴포넌트 라이브러리 목록을 가져와 Code Connect 매핑에 씀.
  • Code Connect Figma 컴포넌트와 코드 컴포넌트를 양쪽으로 이어줍니다.
03

MCP 서버 등록

~/.claude/settings.json 또는 프로젝트 .claude/settings.json에 아래 내용을 추가합니다.

~/.claude/settings.json
{ "mcpServers": { "figma": { "command": "npx", "args": ["-y", "@figma/mcp"], "env": { "FIGMA_ACCESS_TOKEN": "figd_xxxxxxxxxxxxxxxx" } } } }
CLI로 추가하려면: claude mcp add figma --transport http https://mcp.figma.com/v1/sse
브라우저 OAuth로 등록됩니다.
04

Access Token 발급

1
Figma 계정 설정 접속
figma.com → 우측 상단 프로필 → Settings
2
Personal Access Token 탭
Security 섹션 → Personal access tokens
3
토큰 생성
Generate new token → 이름 claude-code-mcp → Scopes: File content: read
4
settings.json에 입력
발급된 figd_... 토큰을 FIGMA_ACCESS_TOKEN에 붙여넣습니다.
05

Claude Code

07

한계 및 주의사항

Figma API는 분당 요청 제한이 있습니다. AI가 반복 호출하면 429 Too Many Requests 오류가 납니다. 대용량 파일은 JSON Exporter 스킬로 한 번 뽑아서 로컬 파일로 쓰세요.

없는 요소를 만들거나 값을 잘못 읽기도 합니다. 픽셀 단위 정확도가 필요하면 JSON 추출도 함께 쓰세요.
